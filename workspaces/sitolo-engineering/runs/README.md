# Engineering Run Records

Run directories are per-run working artifacts, not the current phase pointer.

The `pr009-part8/` directory contains a prior Phase 4 Part 8 / PR-009 run. It is retained for traceability, not deleted or treated as current work. Its contents can be consulted only when relevant and must be assessed against current repository evidence.

For new work:
1. Start at the root ICM router and select the owning workspace.
2. Read `docs/current_implementation_status.md` and `docs/phase_execution_guide.md`.
3. Start a fresh Stage 01 Select run for the active phase.
4. Do not resume a prior run unless the human explicitly selects it.

A folder or file's presence does not establish approval, correctness, verification or phase completion.
